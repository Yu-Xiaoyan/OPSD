# 结果总账（results master ledger）

> **本文件是"最终可用数值"的唯一汇总入口**，直接从 `results/**.json` 抽取（2026-07-20 重抽）。
> 各条均可复算：`average_at_n_pct` 字段；配对检验用 `results[].num_correct / val_n`。
> 上游分析文档见 `docs/v0_results.md`（v0 判读）、`docs/number_ledger.md`（Section 3 溯源）。

**锁定 eval 协议**（全表通用，无例外）：
`temperature 1.0 / top_p 1.0 / top_k -1 / min_p 0 / presence_penalty 0 /
max_new_tokens 38912 / thinking ON`；AIME24 / AIME25 / HMMT25 各 30 题 **avg@12**，
MATH500 500 题 **avg@4**。**per-benchmark 标注 N，不跨 N 平均。**
base = 未训练的对应规模 Qwen3（非任何 checkpoint）。

MATH500（avg@4，仅 1.7B 有全套）：base **90.8** / ckpt50 91.9 / ckpt100 92.4 / ckpt150 91.3。

**判读（保守）：**
- **1.7B 明确获益** —— 三个 benchmark 的 ckpt100 全部显著（p=.008/.038/.046），
  AIME25 ckpt150 p=.002 最稳。
- **4B / 8B 的效应基本落在噪声内** —— 配对 SE 约 ±2–3pp，27 个检验里只有 3 个 p<.05，
  且 8B AIME24 在 ckpt50/150 恰好 **+0.0**。
- **不能声称"增益随规模单调衰减"**：4B AIME24 ckpt50 (+5.3) 反而是全表最强的显著项之一，
  AIME25 上 8B 三个 ckpt 全部 ≈+3.5 且方向一致，非单调。
- **多重比较未校正**（共 27 个检验），且 4B/8B 为**单 seed**。上述 p 值只作参考强度，
  不作独立显著性声明。

### v2 死因归因（#2，预注册于 `docs/copy.md`，ckpt100 AIME24 avg@12 单点）

| 臂 | 含义 | AIME24 | vs base 49.2 |
|---|---|--:|--:|
| v2 main | B + C′ 全开 | 27.8 | −21.4 |
| **noCp**（纯 B） | 只留漂移扣除 −γ·log π_S0 | **27.2** | **−22.0** |
| noB（纯 C′） | 只留 λ·max(δ,0) | 39.2 | −10.0 |

按预注册判读：**两臂皆崩 → 叠加与各自均有份**；量级上 纯 B (27.2) ≈ 全开 (27.8)，
**B 部件（PMI 式漂移扣除）是主导死因**。预注册明确"**只归因，不翻案**"——A 路线裁决与闸门不变。
